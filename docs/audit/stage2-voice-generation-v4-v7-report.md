## 3. Architecture & Implementation Breakdown (V4–V7)

### V4 — Voice Profiles & Delivery Presets
- **Module**: `backend/features/workspace/voice_generation/profiles/delivery_presets.py`
- **Delivery Presets**:
  - `cinematic_narrator`: speed 0.92x, pitch -1.0, high intensity, dramatic cadence.
  - `motivational`: speed 1.06x, pitch 0.0, high intensity, urgent cadence.
  - `calm`: speed 0.88x, pitch -0.5, low intensity, serene cadence.
  - `dramatic`: speed 0.94x, pitch -1.5, high intensity, intense cadence.
  - `energetic`: speed 1.12x, pitch +1.0, high intensity, upbeat cadence.
- **Capability Filtering**: [`resolve_voice_and_delivery`](file:///c:/Users/dheen/project/ApexMind.ai/backend/features/workspace/voice_generation/profiles/delivery_presets.py#L96) inspects the provider's `ProviderCapabilities`. If `supportsPitch` is `False` (Piper / pyttsx3), pitch is clamped to `0.0`. If `supportsEmotion` is `False`, emotion is set to `None`, ensuring provider transparency.

### V5 — Scene-by-Scene Multi-Scene Orchestration
- **Module**: `backend/features/workspace/voice_generation/engine/voice_orchestrator.py`
- **Orchestration**:
  - Ingests approved Stage 1 storyboard documents (`ScriptDocument` / SQLite).
  - Parallel task pool with semaphore concurrency control (default: 4 concurrent workers).
  - Caches audio via composite hash: `SHA256(provider|voice|speed|pitch|lufs|format|version|text)`.
  - Mode Support: `mode="all"` generates all scenes; `mode="selected_scenes"` re-synthesizes only specified scenes, loading existing files for untouched scenes.

### V6 — Audio Validation & Normalization
- **Module**: `backend/features/workspace/voice_generation/services/audio_processor.py`
- **Functions**:
  - [`validate_wav_integrity`](file:///c:/Users/dheen/project/ApexMind.ai/backend/features/workspace/voice_generation/services/audio_processor.py#L29): Decodes WAV headers, verifies minimum duration ($>0.4\text{s}$), detects silence ($\text{RMS} < -55\text{ dBFS}$), and detects digital clipping ($\text{Peak} \ge 0.999$).
  - [`process_and_normalize_audio`](file:///c:/Users/dheen/project/ApexMind.ai/backend/features/workspace/voice_generation/services/audio_processor.py#L102): Trims leading/trailing dead silence to 50ms, applies EBU R128 `loudnorm` filter targeting configured LUFS (default $-16.0\text{ LUFS}$ for streaming, $-23.0\text{ LUFS}$ for broadcast), and enforces true-peak ceiling (default $-1.0\text{ dBTP}$).

### V7 — Master Narration Assembly & Timeline Mapping
- **Module**: `backend/features/workspace/voice_generation/services/audio_assembler.py`
- **Assembly Logic**:
  - Concatenates scene audio buffers in storyboard order with 120ms inter-scene silence padding.
  - Applies master-level loudness normalization and True Peak limiting.
  - Atomic promotion: saves `narration_master_vN.wav` and atomically copies to canonical `narration_master.wav`. If assembly fails, previous master audio remains untouched.
- **Timing Mapping Differentiation**:
  - `storyboardStartTime`: Visual scene start from Stage 1.
  - `storyboardDuration`: Visual scene duration from Stage 1.
  - `speechStartOffset`: Delay within scene before speech begins.
  - `actualDuration`: Physical duration of the generated WAV file.
  - `compactMasterStart` / `compactMasterEnd`: Position within continuous `narration_master.wav`.
  - `videoTimelineStart` / `videoTimelineEnd`: Position on global video timeline (`storyboardStartTime + speechStartOffset`).
  - `pacingStatus`: Flags `warning_exceeds_scene` if `actualDuration > storyboardDuration + 0.35s`.
