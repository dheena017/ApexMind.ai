# ApexMind Website Data & Storage (`backend/data`)

This directory is strictly reserved for the website's persistent data, database files, and media assets. No Python code is stored here.

### Contents:
- **`apexmind.db`**: SQLite database storing channels, quote memory, published videos, automations, and media presets.
- **`audio/`**: Synthesized vocal voiceovers, narration clips, and audio tracks.
- **`media/`**: Rendered video clips, YouTube Shorts video files, and visual backdrop assets.
