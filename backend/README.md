# Backend

Server-side code and API implementations for ApexMind.

- `server.ts` is the Node/Express entry point used by `npm run dev`; it serves the API and Vite development app.
- `main.py`, `database.py`, and `gemini_service.py` provide a separate FastAPI implementation and SQLite/Gemini helpers.
- The sibling folders document reserved places for future backend modules. The current implementation is still in these top-level files.

For setup and run commands, see the project [README](../README.md).
