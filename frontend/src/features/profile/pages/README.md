# Profile pages

Each profile destination has a separate screen:

- `ProfilePage.tsx` — creator overview, saved identity and preferences, linked channels, account/usage status, badges, recent activity, and an actionable setup checklist.
- `ProfileDetailsPage.tsx` — creator identity, bio, and public links.
- `ProfilePreferencesPage.tsx` — script and voice defaults.
- `ProfileChannelsPage.tsx` — connected channel controls.
- `ProfileActivityPage.tsx` — activity history and milestones.
- `ProfileUsagePage.tsx` — creation counts from saved studio activity.
- `ProfileSecurityPage.tsx` — account security status and unsupported-control disclosures.
