# Dashboard Feature Module

The Dashboard feature provides creators with an executive command center displaying:
- Top-line KPIs: Total studio videos, AI scripts stored in quote memory, total audience views, audience likes, and connected YouTube channels.
- Quick prompt spark launcher: Instant trending topics to trigger the AI generation pipeline directly in the studio.
- Production feed: Recent website videos with inline modal playback, duration/aspect ratio tags, and quick edit links.
- Script monologues history: Recent quotes with one-click copy and studio reload.
- YouTube channel pulse: Subscriber count, upload totals, and verification status.
- Real-time engine telemetry: Gemini AI status, SQLite connectivity, audio cache metrics, and system uptime.
