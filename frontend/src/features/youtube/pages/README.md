# YouTube pages

Contains `YouTubePage.tsx`, the interface for channel connections, published video data, and automation controls.

Key Pages:
- `YouTubePage.tsx`:
  - Main YouTube dashboard for connecting channels, viewing analytics, managing automations, and navigating to other YouTube-specific pages.
- `YouTubeHomePage.tsx`:
  - Overview tab: quick stats, top videos, latest shorts, trending for you.
- `YouTubeVideosPage.tsx`:
  - Detailed videos section: list, upload, edit, scheduling, studio, live sync.
- `YouTubeShortsPage.tsx`:
  - Shorts management: vertical grid, live sync, auto-upload, trending shorts.
- `YouTubePlaylistsPage.tsx`:
  - Playlist management: create, edit, and sync YouTube playlists.
- `YouTubePostsPage.tsx`:
  - Community posts: view and manage posts for your YouTube channel.
