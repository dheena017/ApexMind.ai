# Frontend source

Root of the browser application source.

- `main.tsx` mounts the React app and imports the global stylesheet.
- `App.tsx` manages top-level page state and the demo login gate.
- `index.css` loads Tailwind and shared styles.
- `app/` contains route definitions, page selection, and the signed-in shell.
- `features/` contains product features; `shared/` contains reusable UI and styles.
